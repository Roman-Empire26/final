title: "Learn more"
---

The Doctrina christiana shows how a new tool can completely change the process of communication. Printing made it possible to create multiple copies from the same source instead of reproducing each one by hand. This allowed information to move farther and reach more people. The tool did more than make the process faster. It changed the scale of communication and made repeated copies part of the process. This connects to the fluidity of process because the way knowledge moves depends on the tools available. When the tool changes, the process of producing and sharing information changes with it.
